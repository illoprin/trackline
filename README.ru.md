Trackline — нелинейный редактор профессионального уровня для тех, кто монтирует для интернета:
привычные панели, рабочие пространства, инструменты и горячие клавиши. В основе — собственный
движок на Rust: свои кодеки H.264, HEVC, ProRes и AAC, GPU-композитор с линейным светом, точное
целочисленное время (правки не «плывут»), и движок, где каждое действие — это команда, которой
ИИ-агент может управлять так же точно, как человек.

## Что добавляет Trackline

Trackline сохраняет движок FilmCraft и добавляет инструменты, к которым монтажёр тянется каждый день.

### Spectrum Analyzer на мастер-шине

Живой спектроанализатор рисует АЧХ всего, что приходит на мастер, **после** мастер-эффектов — так
видно ровно то, что уходит из микшера. Им удобно ловить мутную нижнюю середину, находить резонансный
звон или настраивать де-эссер на слух и по картинке во время воспроизведения.

<p align="center"><sub><b>Видно не только уровень, но и сам микс.</b> Спектроанализатор следует за мастер-шиной через её эффекты.</sub></p>

### Новые эффекты — видео и звук

- **Camera Shake** (видео): процедурная тряска «с рук» с настройками амплитуды, частоты и поворота.
- **Gate** (звук): полноценный гейт с Threshold, Attack, Release, Hold, Floor и Gain, секцией
  sidechain (Floor, Highpass, Lowpass) и переключателем **Inverse**, чтобы слышать то, что гейт режет.
- **Bitcrusher** и **Retro Wiggle** (звук): лоу-фай понижение битности и «кассетное» дрожание высоты.
- Плюс переработанный выбор цвета с полем **hex**, которое можно копировать и вставлять.

### Effect Controls, заточенные под скорость

- **Выделяйте и правьте много кейфреймов сразу** — рамкой, затем двигайте, удаляйте (`Del`) или
  меняйте интерполяцию пакетно. `Alt`+drag дублирует кейфреймы.
- **Копируйте и вставляйте эффекты и кейфреймы** (`Ctrl+C` / `Ctrl+V`) между клипами, дорожками и
  даже сиквенциями. Вставка на выделение кладёт эффекты туда, куда нужно; вставка кейфреймов сама
  применит недостающий эффект относительно плейхеда.
- **Меняйте порядок эффектов перетаскиванием**, с акцентной полоской места вставки и курсором-рукой,
  как при переупорядочивании вкладок.
- **«Пилюли» кейфреймов** на свёрнутом эффекте показывают его анимацию с первого взгляда, как в
  Premiere Pro.
- **Alt+колесо зумирует дорожку кейфреймов к плейхеду**, а перетаскивание числа «прилипает» к
  курсору, поэтому большие значения больше не упираются в край окна.

<p align="center"><sub><b>Кейфреймы как объекты.</b> Выделяйте много, меняйте интерполяцию пакетно, копируйте на другой клип, переставляйте эффекты перетаскиванием.</sub></p>

### Audio Track Mixer: пресеты и эффекты между дорожками

- **Сохраните всю дорожку как пресет** с именем и описанием и применяйте его к любой дорожке.
- **Копируйте эффекты с одной дорожки и вставляйте на другую** — между дорожками и сиквенциями —
  через общий буфер, заполняя столько слотов, сколько помещается.
- **Удалите все эффекты дорожки** одним нажатием.

### Качество жизни на таймлайне

- **Аудиопереходы** с невидимой линией разграничения: до неё вы меняете громкость, после — длину
  перехода; drag за линию меняет длину (короче одного кадра — удаление), `Alt` даёт
  экспоненциальный переход, `Del` удаляет выделенный аудиопереход.
- **Тримминг сразу нескольких выделенных клипов** — trim left/right и изменение длины применяются ко
  всему выделению.
- **Вставка учитывает целевые дорожки**, а не те, с которых копировали.
- **Плашки клипов** со скруглением 4 px и мягкой внутренней подсветкой, а waveform и превью
  обрезаются по скруглению.

### Текстовые стили как ассеты проекта

- **Переиспользуемые текстовые стили** живут в окне проекта (ассет `ItemKind::TextStyle` с иконкой
  `T`), экспортируются и импортируются как `.fstyle` и применяются к любому числу текстовых объектов
  через контекстное меню, меню клипа на таймлайне, drag-and-drop или инспектор — с **Update Style**
  (push) и **Unlink Style**.
- **Двойной клик выделяет слово** при редактировании текста, **поиск шрифта** фильтрует список, а
  **копирование/вставка слоёв** работает в Essential Graphics.

### Исправления для Linux

- **Drag-and-drop из файлового менеджера работает на Wayland**, а вставка файла из буфера больше не
  добавляет лишний `\r` в путь.

## Скучные технические детали

### Форматы и кодеки

Без FFmpeg внутри. Видеокодеки, AAC, Opus и контейнеры — наш код на Rust, реализованный по публичным
спецификациям ITU-T, ISO и IETF и проверяемый кадр за кадром против ffmpeg как внешнего оракула.

| | Декод | Энкод | Примечания |
|---|:---:|:---:|---|
| **H.264 / AVC** | ✓ | ✓ | Декодер бит-в-бит на 37+ потоках; энкодер High/Main/Baseline, CABAC, B-кадры, CRF/CBR/VBR/2-pass |
| **HEVC / H.265** | ✓ | | Main и Main 10, тайлы, WPP, PCM, долгосрочные ссылки |
| **Apple ProRes** | ✓ | ✓ | Декод от 422 Proxy до 4444 XQ; экспорт 422 HQ |
| **AAC-LC** | ✓ | ✓ | |
| **VP8 / VP9** | ✓ | | Профили, 8/10/12 бит, alpha в WebM, тайлы и суперфреймы |
| **AV1** | ✓ | | Main-профиль, 4:2:0 и монохром 8/10 бит, film grain и superres |
| **Opus** | ✓ | | SILK, CELT, hybrid и multistream surround |
| **DNxHD / DNxHR** | ✓ | ✓ | SMPTE ST 2019-1, 8/10/12 бит; экспорт DNxHR в MOV |
| **MJPEG, PCM** | ✓ | ✓ | |
| **MP3, FLAC, ALAC, Vorbis** | ✓ | | Через крейт [symphonia](https://github.com/pdeljanov/Symphonia), позже заменим своим |
| **MP4 / MOV** | ✓ | ✓ | Fragmented MP4, edit lists, дорожки таймкода |
| **Matroska / WebM** | ✓ | | Lacing, Cues, метаданные цвета HDR |
| **AVI** | ✓ | | AVI 1.0 и OpenDML; MJPEG, H.264, HEVC и несжатый RGB/YUV с PCM, MP3, MP2 или AC-3 |
| **Стиллы** | ✓ | ✓ | PNG, JPEG, GIF, WebP, TIFF и BMP; экспорт PNG-секвенций и анимированного GIF |

Также импортируются: MPEG-2/MPEG-1, AC-3, MP2, MXF (OP1a/OP-Atom), транспортные и программные
потоки MPEG, Ogg и секвенции изображений. Аппаратное декодирование на macOS (VideoToolbox), Windows
(Media Foundation) и, для H.264/HEVC, на Linux (VA-API); экспорт H.264 может использовать энкодер
NVIDIA, а экспорт H.265 — только аппаратный (NVENC на Windows, VideoToolbox на macOS).

### Экспорт и обмен

- **H.264 MP4 с AAC на собственных энкодерах**, а также Apple ProRes 422 HQ и Motion JPEG в
  QuickTime, MXF OP1a/OP-Atom, PNG-секвенции, анимированный GIF и WAV. Фоновые задачи с прогрессом и
  отменой; превью рендера кэшируются по содержимому.
- **Обмен:** FCP 7 XML (xmeml), FCPXML 1.9–1.11, OpenTimelineIO, CMX 3600 EDL, AAF (Edit Protocol)
  и OMF 2.0.
- Собственные проекты Trackline используют формат FilmCraft `.fcproj`, поэтому существующие проекты
  FilmCraft открываются без изменений.

### Автоматизация

Каждый пункт меню, кнопка, ползунок и перетаскивание — это **команда** с идентификатором,
типизированными параметрами и состоянием доступности. Всего более 650 команд движка
(`trackline-cli commands` выводит список). UI, CLI, JSON-канал управления и **MCP-сервер**
диспетчеризуют одни и те же команды, поэтому Claude или любой агент может резать, триммить, красить,
сводить и экспортировать так же, как человек.

```jsonc
// по каналу управления (JSON lines поверх TCP) или как вызовы инструментов MCP
{"method": "engine.execute", "params": {"command": "timeline.place",
  "params": {"item": 1, "track": "V1", "seconds": 0, "sourceIn": 284298240000000, "duration": 1270080000000}}}
{"method": "ui.screenshot", "params": {"path": "frame.png"}}
```

### Сборка из исходников

Trackline собирается свежим стабильным Rust (edition 2024; см. `rust-version` в `Cargo.toml`).

```sh
git clone https://github.com/illoprin/trackline
cargo run --release -p filmcraft                    # десктопное приложение (бинарник: trackline), с демо-проектом
cargo run --release -p filmcraft -- --control 9876  # плюс JSON-канал управления
cargo run --release -p filmcraft-cli -- commands     # список всех команд движка (бинарник: trackline-cli)
cargo run --release -p filmcraft-cli -- mcp          # MCP-сервер (headless)
```

Японский текст в интерфейсе и титрах берётся из
[craft-fonts](https://github.com/storytold/craft-fonts), необязательного входного каталога сборки:

```sh
git clone https://github.com/storytold/craft-fonts ../craft-fonts
CRAFT_FONTS_DIR="$PWD/../craft-fonts" cargo run --release -p filmcraft
```

Протокол управления описан в [docs/control-protocol.md](docs/control-protocol.md).

> Trackline пока не публикует готовые сборки. Релизы оригинального FilmCraft — на его
> [странице релизов](https://github.com/storytold/filmcraft/releases), но это сборки FilmCraft.

### Статус

Trackline наследует движок FilmCraft, который в стадии **alpha** и быстро развивается. Сегодня
работают монтаж, тримминг, multicam, цвет, кейфреймы, эффекты, титры, субтитры, сведение, кодеки и
экспорт. Известные пробелы: нет нативного импорта `.prproj`, нет хостинга плагинов, экспорт H.265 и
AV1 только аппаратный (или отсутствует), а медиа камер и телефонов проверены меньше, чем
conformance-потоки.
