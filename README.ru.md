Trackline — нелинейный редактор профессионального уровня для тех, кто монтирует для интернета:
привычные панели, рабочие пространства, инструменты и горячие клавиши. В основе — собственный
движок на Rust: свои кодеки H.264, HEVC, ProRes и AAC, GPU-композитор с линейным светом, точное
целочисленное время (правки не «плывут»), и движок, где каждое действие — это команда, которой
ИИ-агент может управлять так же точно, как человек.

## Монтаж

<p align="center">
  <img src="docs/images/filmcraft-assembly.png" alt="Рабочее пространство Assembly: корзины с превью, мониторы Source и Program, таймлайн из трёх дорожек с музыкой и измерителями громкости" width="100%">
</p>

**Таймлайн, который вы уже знаете.** Мониторы Source и Program, корзины с превью,
многодорожечный таймлайн с кнопками патча и целей, блокировками синхронизации и связанным
выделением, и панели, которые стыкуются в любое рабочее пространство.

- **Трёхточечный монтаж.** Отметьте In и Out в Source, затем вставьте (insert) или наложите
  (overwrite) на выбранные дорожки. Lift и extract убирают диапазоны обратно.
- **Все виды тримминга.** Ripple, roll, slip, slide, rate stretch и razor. Отдельные Trim и Slip
  мониторы, динамический тримминг во время воспроизведения и ripple-trim до плейхеда.
- **Точное время.** Каждая правка считается в целых тиках (254 016 000 000 в секунду), что делится
  без остатка на все частые частоты кадров и дискретизации: 23.976, 29.97 drop-frame и 59.94 —
  точные, а не приближённые.
- **Детали, важные для профи.** Маркеры с цветами и длительностями, вложенность (nesting),
  копирование/вставка и paste insert, ripple delete и закрытие дыр, привязка и неограниченный undo
  с панелью History.
- **Работа не теряется.** Атомарные сохранения, кольцевые автосохранения и журнал
  восстановления после сбоя, который возвращает несохранённые изменения.

## Цвет

<p align="center">
  <img src="docs/images/filmcraft-color.png" alt="Рабочее пространство Color: монитор Program с живыми waveform и vectorscope" width="100%">
</p>

Полная панель цветокоррекции в порядке работы колориста:

- **Basic Correction:** температура и оттенок, экспозиция, контраст, света, тени, белые, чёрные,
  насыщенность.
- **Creative:** встроенные локи с регулятором интенсивности, а также faded film, sharpen и vibrance.
- **Curves:** редактор кривых RGB с монотонно-кубической интерполяцией, а также hue vs saturation,
  hue vs hue, hue vs luma, luma vs saturation и sat vs sat.
- **Color Wheels:** колёса тени/полутона/света, у каждого свой регулятор светлоты.
- **HSL Secondary:** кеинг по тону, насыщенности и яркости, просмотр маски и коррекция только
  выделенного. Плюс винье́тка (количество, середина, округлость, растушёвка).

Вся коррекция идёт в линейном свете, в 32-битном float, а waveform и vectorscope считаются по
скорректированному кадру.

## Эффекты

<p align="center">
  <img src="docs/images/filmcraft-effects.png" alt="Рабочее пространство Effects: Effect Controls с Motion, Opacity и цветокоррекцией и открытый браузер эффектов" width="100%">
</p>

- **Большая корзина видеоэффектов**, legacy-эффекты и десятки переходов: размытия, кеи, искажения,
  свечения, эффекты immersive video, Posterize Time, Echo, dissolve, шторки, ирисы, push, slide,
  zoom и другое.
- **Motion и opacity на каждом клипе:** положение, масштаб, поворот, точка привязки, устранение
  мерцания и режимы наложения.
- **Продвинутый кейфрейминг:** линейные, Безье, auto/continuous Безье, hold, ease in/ease out, с
  графиками значения и скорости и общим навигатором кейфреймов.
- **GPU-композитор** на wgpu (Metal, Vulkan, DirectX 12, WebGPU), который берёт YUV прямо из
  декодера и смешивает в линейном свете, плюс CPU-путь, проверяемый против него.

## Звук

- **Измерители громкости по вещательным стандартам:** momentary, short-term и integrated, а также
  true peak по ITU-R BS.1770 и EBU R128, рядом с пиковыми измерителями.
- **Клиповые эффекты на собственной DSP:** параметрический EQ, ФВЧ/ФНЧ/полосовой, динамика,
  true-peak лимитер, delay, reverb, DeNoise, DeHummer, инверсия и pitch shift — всё с кейфреймами.
- **Audio Track и Clip Mixer:** фейдеры, панорама, mute, solo, слоты вставок, sends, субмиксы и
  Mix-дорожка, сэмпл-точно и с компенсацией задержки, с автоматизацией read/latch/touch/write.
- **Воспроизведение по аудио-часам:** мастер-клок — звуковая карта, поэтому изображение следует за
  звуком.

## Титры и субтитры

- **Настоящий текстовый движок:** шейпинг OpenType с кернингом и лигатурами, двунаправленный текст,
  перенос строк, трекинг и интерлиньяж — резкий при любом масштабе и повороте.
- **Инструменты Type, Shape и Pen** на мониторе Program, редактируются в панели Properties и
  анимируются кейфреймами.
- **Субтитры:** дорожки в форматах Subtitle, CEA-608, CEA-708 и Teletext; импорт и экспорт SRT,
  WebVTT и SCC с точностью до кадра, вжигание субтитров в экспорт.

## Форматы

Без FFmpeg внутри. Видеокодеки, AAC, Opus и контейнеры — наш код на Rust, реализованный по
публичным спецификациям ITU-T, ISO и IETF и проверяемый кадр за кадром против ffmpeg как внешнего
оракула.

| | Декод | Энкод | Примечания |
|---|:---:|:---:|---|
| **H.264 / AVC** | ✓ | ✓ | Декодер бит-в-бит на 37+ потоках; энкодер с профилями High/Main/Baseline, CABAC, B-кадрами, CRF/CBR/VBR/2-pass |
| **HEVC / H.265** | ✓ | | Main и Main 10, тайлы, WPP, PCM, долгосрочные ссылки |
| **Apple ProRes** | ✓ | ✓ | Декод от 422 Proxy до 4444 XQ; экспорт 422 HQ |
| **AAC-LC** | ✓ | ✓ | |
| **VP8 / VP9** | ✓ | | Профили, 8/10/12 бит, alpha в WebM, тайлы и суперфреймы |
| **AV1** | ✓ | | Main-профиль, 4:2:0 и монохром 8/10 бит, film grain и superres |
| **Opus** | ✓ | | SILK, CELT, hybrid и multistream surround |
| **DNxHD / DNxHR** | ✓ | ✓ | SMPTE ST 2019-1, 8/10/12 бит; экспорт DNxHR в MOV |
| **MJPEG, PCM** | ✓ | ✓ | |
| **MP3, FLAC, ALAC, Vorbis** | ✓ | | Через крейт [symphonia](https://github.com/pdeljanov/Symphonia), позже заменим своим |
| **MP4 / MOV** | ✓ | ✓ | Fragmented MP4, edit lists, дорожки таймкода |
| **Matroska / WebM** | ✓ | | Lacing, Cues, метаданные цвета HDR |
| **AVI** | ✓ | | AVI 1.0 и OpenDML; Motion JPEG, H.264, HEVC и несжатый RGB/YUV с PCM, MP3, MP2 или AC-3 |
| **Стиллы** | ✓ | ✓ | PNG, JPEG, GIF, WebP, TIFF и BMP (анимированные GIF/APNG/WebP как клипы); экспорт PNG-секвенций и анимированного GIF |

Также импортируются: MPEG-2/MPEG-1, AC-3, MP2, MXF (OP1a/OP-Atom), транспортные и программные
потоки MPEG, Ogg и секвенции изображений. Аппаратное декодирование работает на macOS
(VideoToolbox), Windows (Media Foundation) и, для H.264/HEVC, на Linux (VA-API); экспорт H.264 может
использовать энкодер NVIDIA, а экспорт H.265 — только аппаратный (NVENC на Windows, VideoToolbox на
macOS).

## Экспорт

<p align="center">
  <img src="docs/images/filmcraft-export.png" alt="Режим Export: пресеты для соцсетей слева, превью в центре и настройки H.264 справа" width="100%">
</p>

- **H.264 MP4 с AAC на собственных энкодерах**, а также Apple ProRes 422 HQ и Motion JPEG в
  QuickTime, MXF OP1a/OP-Atom, PNG-секвенции, анимированный GIF и WAV.
- **Фоновые задачи** с прогрессом и отменой — можно продолжать монтаж во время рендера.
- **Превью рендера:** полоса рендера помечает сегменты зелёным, жёлтым или красным, а превью
  кэшируются по содержимому, поэтому правка обесценивает только затронутое.

## Interchange

Переносите таймлайны между Trackline и другими редакторами:

- **FCP 7 XML (xmeml)** и **FCPXML 1.9–1.11**.
- **OpenTimelineIO** (round-trip через `metadata.filmcraft`).
- **CMX 3600 EDL** с drop-frame таймкодом и переходами.
- **AAF (Edit Protocol)** и **OMF 2.0** для аудиопоста.

Собственные проекты Trackline используют формат FilmCraft `.fcproj`, поэтому существующие проекты
FilmCraft открываются без изменений.

## Автоматизация

Каждый пункт меню, кнопка, ползунок и перетаскивание — это **команда** с идентификатором,
типизированными параметрами и состоянием доступности. Всего более 650 команд движка (`trackline-cli
commands` выводит список). UI, CLI, JSON-канал управления и **MCP-сервер** диспетчеризуют одни и те
же команды, поэтому Claude или любой агент может резать, триммить, красить, сводить и экспортировать
так же, как человек. У каждого виджета есть id автоматизации, так что агент может кликать, тащить,
печатать и делать скриншоты.

```jsonc
// по каналу управления (JSON lines поверх TCP) или как вызовы инструментов MCP
{"method": "engine.execute", "params": {"command": "timeline.place",
  "params": {"item": 1, "track": "V1", "seconds": 0, "sourceIn": 284298240000000, "duration": 1270080000000}}}
{"method": "ui.screenshot", "params": {"path": "frame.png"}}
```

## Об этом форке

- **Upstream:** [storytold/filmcraft](https://github.com/storytold/filmcraft) команды ArtCraft и
  участников FilmCraft. Сообщения об ошибках самого движка стоит направлять в upstream; Trackline
  следит за тем же проектом.
- **Что меняет Trackline:** название продукта, идентификатор приложения (`ru.illoprin.trackline`),
  иконку и упаковку, а также ребрендинг в разделах About/Help. Движок, кодеки, формат проектов и
  набор команд — это upstream.
- **Не официальный продукт:** Trackline не связан с командой ArtCraft, не спонсируется, не одобрен и
  не поддерживается ею. Название и логотипы ArtCraft — её товарные знаки и здесь не используются
  (лицензия на бренд требует, чтобы форки их убирали).
- **Пути данных сохранены для совместимости:** настройки, автосохранение и восстановление остаются в
  прежних пользовательских каталогах FilmCraft (например, `~/.local/share/filmcraft`), поэтому данные
  прежних сборок находятся снова.

## Сборка из исходников

Trackline собирается свежим стабильным Rust (edition 2024; см. `rust-version` в `Cargo.toml`).

```sh
git clone https://github.com/storytold/filmcraft   # актуально, пока у Trackline нет публичного репозитория
cargo run --release -p filmcraft                    # десктопное приложение с демо-проектом
cargo run --release -p filmcraft -- --control 9876  # плюс JSON-канал управления
cargo run --release -p filmcraft-cli -- commands     # список всех команд движка
cargo run --release -p filmcraft-cli -- mcp          # MCP-сервер (headless)
```

Японский текст в интерфейсе и титрах берётся из
[craft-fonts](https://github.com/storytold/craft-fonts), необязательного входного каталога сборки:

```sh
git clone https://github.com/storytold/craft-fonts ../craft-fonts
CRAFT_FONTS_DIR="$PWD/../craft-fonts" cargo run --release -p filmcraft
```

Протокол управления описан в [docs/control-protocol.md](docs/control-protocol.md).

> Trackline пока не публикует готовые сборки. Релизы upstream FilmCraft доступны на его
> [странице релизов](https://github.com/storytold/filmcraft/releases), но это сборки FilmCraft, а не
> Trackline.

## Статус

Trackline наследует движок FilmCraft, который в стадии **alpha** и быстро развивается. Сегодня
работают монтаж, тримминг, multicam, цвет, кейфреймы, эффекты, титры, субтитры, сведение, кодеки и
экспорт.

Главные пробелы, унаследованные от upstream:

- **Импорт проектов `.prproj`.** Файлы `.prproj` пока не открываются; переносите таймлайны через
  FCP7 XML, AAF или OTIO.
- **Нет плагинов.** Нет хостинга VST3 / Audio Units или OpenFX.
- **Кодеки доставки.** H.264 — единственный программный кодек доставки; H.265 экспортируется только
  через аппаратный энкодер; экспорта AV1 пока нет.
- **Реальные медиа.** Декодеры бит-в-бит на conformance-потоках, но файлы камер и телефонов «из
  жизни» проверены меньше.
- **ИИ-функции.** Пока их мало; распознавание речи опционально и по умолчанию выключено.
